Как найти третью сторону треугольника по углу

Если известны две стороны треугольника и угол между ними, третью сторону можно найти по одной формуле. Самый частый практический случай — две равные стороны (равнобедренный треугольник, раствор циркуля, две одинаковые планки или стропила, радиусы окружности): тогда третья сторона — это хорда, и считается она совсем просто. Ниже — формула, калькулятор, таблица и обратная задача: угол по трём сторонам.

Формула: две равные стороны и угол между ними

c = 2a · sin(α / 2)

Здесь a — каждая из двух равных сторон, α — угол между ними (угол при вершине), c — третья сторона (основание). Формула получается из прямоугольного треугольника: высота из вершины делит угол α и основание c пополам, поэтому c/2 = a · sin(α/2). Это та же формула длины хорды, на которой построена Шкала Яковлева: k = sin(α/2) — готовый множитель, c = (a + a) · k.

Пример. Две стороны по 5 см, угол между ними 90°: c = 2 · 5 · sin 45° = 10 · 0,7071 ≈ 7,07 см. При угле 60° третья сторона равна боковой (c = a, треугольник равносторонний), при 180° — удвоенной стороне.

Калькулятор третьей стороны треугольника

Если стороны разные: теорема косинусов

c = √(a² + b² − 2ab · cos γ)

Для двух разных сторон a и b и угла γ между ними точный ответ даёт теорема косинусов. При a = b она превращается в c = 2a · sin(γ/2). Быстрая прикидка по шкале c ≈ (a + b) · sin(γ/2) при разных сторонах немного занижает результат: стороны 3 и 4 под углом 90° дают 4,95 вместо точных 5 (около 1%). Калькулятор выше показывает и точный ответ, и прикидку.

Пример. a = 7, b = 10, γ = 60°: c = √(49 + 100 − 2·7·10·0,5) = √79 ≈ 8,89.

Угол по трём сторонам (обратная задача)

Если известны все три стороны, угол между сторонами a и b находят из той же теоремы косинусов: cos γ = (a² + b² − c²) / (2ab). Для двух равных сторон проще: γ = 2 · arcsin(c / 2a). Так можно проверить угол на детали или на чертеже, измерив только длины рулеткой.

Калькулятор угла по трём сторонам

Пример. Стороны 3, 4 и 5: cos γ = (9 + 16 − 25) / 24 = 0, γ = 90° — это знаменитый «египетский треугольник».

Частые вопросы

Как найти третью сторону по углу между равными сторонами?
По формуле c = 2a·sin(α/2), где a — равная сторона, α — угол между равными сторонами. Например, a = 5, α = 90°: c = 10·sin 45° ≈ 7,07.
Как найти третью сторону, если стороны разные?
По теореме косинусов: c = √(a² + b² − 2ab·cos γ), где γ — угол между сторонами a и b. Например, 7 и 10 под углом 60° дают √79 ≈ 8,89.
Как найти угол треугольника, зная три стороны?
cos γ = (a² + b² − c²) / (2ab), затем γ = arccos(...). Для двух равных сторон a и основания c: γ = 2·arcsin(c / 2a).
Чему равно основание равнобедренного треугольника с углом 60° при вершине?
Основание равно боковой стороне: c = 2a·sin 30° = a. Такой треугольник равносторонний.
Почему прикидка (a + b)·sin(γ/2) меньше точного ответа?
Она точна только при a = b. При разных сторонах она всегда немного занижает результат: 3 и 4 под 90° дают 4,95 вместо 5.
